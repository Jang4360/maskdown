# 03. 이미지 → 문맥 반영 텍스트 변환 기준

> **담당 영역**: 문서(PDF, PPT, HWP, DOCX) 내 삽입 이미지를 어느 수준과 포맷으로 텍스트화할지, 어떤 이미지는 무시/제외할지 기준을 정립합니다.

---

## 핵심 결정 사항
- [ ] 이미지 유형별 변환 깊이 및 출력 포맷 정의
  - 아키텍처 도식 / 흐름도
  - 표 이미지 / 조직도
  - 화면 캡처 (UI, 로그, 설정 화면 등)
  - 장식 요소 / 회사 로고 / 단순 아이콘 (제외 기준)
- [ ] 이미지 문맥 반영을 위한 프롬프트 / 출력 Markdown 형식 가이드
- [ ] 저해상도·깨짐 등으로 해석 불가 시 **추측 금지 → 미처리 보고서 이관** 기준
