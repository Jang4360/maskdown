## 핵심 결정 사항
- [ ] 체크리스트 **기본 필수 항목** vs **문서별 선택 항목** (프리셋 구성)
- [ ] **화이트리스트(예외)** 기준 (자사 제품명, 공개 기술/오픈소스 용어 등)
- [ ] **숨김 데이터 정책**: PPT 발표자 노트, Excel 숨김 시트·메모, 문서 작성자 메타데이터 처리 방식
- [ ] 치환 포맷(`[고객사_1]` 가명화 vs `***`) 및 역치환(매핑 테이블 보관) 필요 여부
