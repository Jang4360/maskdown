# 04. 미처리("못했다") 판정선 및 검수 방식

> **담당 영역**: AI가 추측하지 않고 "처리 불가 / 애매함"으로 보고해야 하는 기준선과, 사람이 최종 결과를 검수·승인하는 워크플로우를 정립합니다.

---

## 핵심 결정 사항
- [ ] **불확실·애매한 항목 처리 정책**
  - 방안 A: 원문 유지 + 보고서에 경고 출력
  - 방안 B: 보수적 마스킹 + 보고서에 확인 요청 출력
- [ ] **"못했다(미처리)" 판정 조건** (신뢰도 임계값, 이미지/표 파싱 실패, 문맥상 모호한 고유명사 등)
- [ ] **누락·미처리 보고서 포맷** (위치: 페이지/문단/이미지, 사유, 원문 스니펫 등)
- [ ] **사람 최종 검수 UX**: CLI + 마크다운 리포트 vs 경량 로컬 웹 UI(체크리스트 선택 + 결과 확인)
